
# Vue Task Manager

Das ist ein kleines Projekt, das ich mit Vue.js 3 entwickelt habe, um meine Kenntnisse in der Webentwicklung zu erweitern und praktisch anzuwenden.

Mit der Anwendung kann man eigene Aufgaben hinzufügen, als erledigt markieren, löschen und nach ihrem Status filtern. Außerdem gibt es einen Dark Mode und die Möglichkeit, Aufgaben im Local Storage des Browsers zu speichern.

## Funktionen

- Neue Aufgaben hinzufügen
- Aufgaben als erledigt markieren
- Aufgaben löschen
- Aufgaben nach Status filtern (Alle, Offen, Erledigt)
- Anzahl aller, offenen und erledigten Aufgaben anzeigen
- Zwischen Light Mode und Dark Mode wechseln
- Aufgaben und Einstellungen im Local Storage speichern
- Responsive Darstellung für verschiedene Bildschirmgrößen
- Kleine Animationen und zusätzliche Interaktionen
- Kleines Easter Egg

## Verwendete Technologien

- Vue.js 3
- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
